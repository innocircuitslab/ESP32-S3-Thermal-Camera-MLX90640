# V4 REAL-PRINT FIX change — rear cover / screw-boss clearance

V4 incorporates fixes from the first real full print: more internal depth, a larger display opening, a centered/wider USB service slot, and screw posts grounded directly to the enclosure floor.

Key V4 geometry changes:

1. Boss tops stop **3.5 mm below the rear body rim**.
2. The rear-cover locating lip has **Ø10.5 mm clearance pockets** around all four boss positions.

The locating lip enters **2.0 mm** into the body, leaving **1.5 mm nominal vertical clearance** above each screw boss before accounting for the extra radial relief.

These changes address the real-print fit issues while preserving the proven cover-lip clearance from V3.
