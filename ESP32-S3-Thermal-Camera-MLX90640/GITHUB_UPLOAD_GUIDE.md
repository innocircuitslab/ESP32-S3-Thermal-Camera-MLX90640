# GitHub upload guide

## Suggested repository name

`ESP32-S3-Thermal-Camera-MLX90640`

## Suggested description

`DIY handheld thermal camera using ESP32-S3, MLX90640 and an ST7789 TFT, with live heat-map interpolation, hotspot readings and a 3D-printed enclosure.`

## Upload

1. Create a new **Public** repository on GitHub.
2. Use the repository name above.
3. Do **not** initialize it with a README, `.gitignore`, or license — these are already included.
4. Extract the ZIP from ChatGPT.
5. Open the extracted `ESP32-S3-Thermal-Camera-MLX90640` folder.
6. Upload **the contents of that folder**, not the ZIP itself.
7. Commit message suggestion:

   `Initial release - ESP32-S3 thermal camera`
